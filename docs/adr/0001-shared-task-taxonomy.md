# 四模块共用任务标签，并允许跨场景关联

2026-10-23，用户确认：能力测评、评分与榜单、价格对比、使用技巧与教程共用一套后台可配置的任务标签；一个内容条目可以带多个标签，一个任务标签可以归属多个场景。场景负责组织入口，任务标签描述具体工作，例如“论文图表”相关内容可以同时出现在科研和专业办公中。

采用统一词表，而非各模块独立维护同名标签，可以避免分类名称和含义逐渐分叉，并保留跨模块寻找同一任务内容的能力；代价是改名、停用和场景调整需要考虑四模块的共同引用。标签显示顺序不决定榜内名次，“综合”仍按具体模型版本人工排名。此决定约束领域关系，不预先指定 Halo 原生 Tag 或插件资源的具体存储方式。
