# 网站架构

本页描述当前源码职责。术语以 [CONTEXT.md](../CONTEXT.md) 为准，稿件结构以 [Schema](../contracts/content-package-v1.schema.json) 为准。

## 组件与数据

网站采用 Halo 2.26、PostgreSQL、Thymeleaf 主题及自有 `plugin-aihyb` 插件。插件后端使用 Java 21，控制台扩展使用 Vue 3；没有另建独立公众前端或修改 Halo 内核。

- `plugin-aihyb/src/main/java`：稿件接收、审核、发布版本保护、公开查询、正文渲染、媒体、任务标签与站点配置。
- `plugin-aihyb/ui/src`：原生文章编辑扩展、稿件结构化字段、审核界面和站点配置。API 客户端由 OpenAPI 生成并随源码保存。
- `plugin-aihyb/src/main/resources/theme-assets`：插件提供的页面样式、交互脚本及运行时品牌图片。
- `themes/shared`：主题定制源文件；`themes/adapters`：部署用模板及哈希清单；`themes/upstream`：生成适配所需的固定上游版本及许可。

Halo 通过官方资源客户端将内容、不可变修订及发布状态存入 PostgreSQL。受管理的原生文章承载当前草稿、批准和公开修订；公开列表、正文和 DTO 读取相同的发布版本。保存草稿不改变已经发布的标题、正文、结构化数据及栏目；批准只适用于明确修订，修改后必须重新审核。

真实稿件和附件是运营数据，保存在 Halo、数据库与 COS，并通过独立备份保护。仓库只保存协议与虚构测试材料。内容制作、视频生产及来源资料归档均在仓库外进行。

## 页面与编辑规则

首页包含能力测评、评分与榜单、价格对比、使用技巧与教程四个入口。「最新资讯」自动汇集最新公开发布的文章：首页展示最新五篇，独立列表提供分页。资讯、能力测评、教程以及未归入上述模块的普通文章都会进入汇总，无需额外选择资讯分类；任何公开栏目包含「评分与榜单」或「价格对比」的内容暂时排除，多分类文章只出现一次。汇总卡片保留原栏目和原文链接，按发布时间倒序排列，日期使用北京时间。稿件包的 `content.section=news` 仍控制文章正文栏目及样式，`content.news_date` 保留原收录日期；汇总只在缺少发布时间时用其兼容旧数据。

后台直接编辑的普通文章按原生分类别名 `reviews`、`leaderboards`、`prices`、`tutorials`、`news` 进入对应模块；选择多个模块分类时分别收录。没有匹配模块分类的普通文章在公开结果中使用 `kind=news`，只进入最新文章汇总。首页和栏目列表共用公开查询，普通文章使用标题、摘要、发布时间、可选封面及原文链接展示，不生成评分、榜单表格、价格方案或核验结论。稿件包继续按发布版本展示结构化信息。公开结果中的 `content.sections` 记录普通文章的栏目，`content.published_at` 用于合并排序，不作为标准稿件输入字段。

场景和任务标签共用可配置词表，一个任务标签可以归属多个场景。“综合”按具体模型版本人工排序，不从不同测评中自动合成分数。决策依据见[任务分类 ADR](adr/0001-shared-task-taxonomy.md)。

页脚不再重复展示 Logo 与品牌宣传语，只保留五个栏目和内容归档入口；场景及任务标签在栏目页筛选区展示，避免在页脚按栏目重复展开。桌面端导航居中横排，手机端两列排列，继续按站点配置居中展示有效二维码。版权与备案信息由 Earth 主题在导航下方居中同行展示，窄屏空间不足时自然换行；备案号和链接仍只从主题现有备案设置读取。插件独立页脚继续保留版权信息。

正文采用摘要、关键信息、章节导航和来源卡片。测评保留过程及样例；榜单保留成绩与排名依据；价格同时呈现全部方案、权益、限制和同任务用量条件；教程保留准备清单与操作步骤。没有核验的数据不得作为真实排名或价格发布。视觉取舍见[设计参考](design-references.md)。

## 媒体、发现入口与权限

附件由 Halo 管理稳定引用，文件位于私有 COS。公开图片经发布版本及权限检查后短期签名跳转，私有预览、视频和下载仍通过受控网关；Markdown 使用 `asset://附件ID`。服务端限制链接、媒体类型、附件归属及可公开字段。

搜索、Feed 和站点地图必须遵守草稿与公开修订隔离。插件依赖 Feed >=1.5.0，共享事件 API 作为 `compileOnly` 依赖保存了来源与许可。升级相关组件需要重新验证缓存失效、别名及标签路由。

数据库和 Halo 文件共同构成恢复所需数据，单份文章 JSON 不替代站点备份。CDN、定时备份、完整负载验收及可靠缓存失效重试尚未纳入本次仓库整理；历史验证结论位于外部归档，不将其视为本轮重新验证。
